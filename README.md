# USA AI Employment Analysis (2019–2023)

## Project Overview

This project is part of the Year 4 Data Visualisation module at CCT College Dublin.

The objective is to analyse employment statistics in the United States, focusing on occupations related to Artificial Intelligence (AI), Data Science, and Software Development.

Using data from the U.S. Bureau of Labor Statistics (BLS), the project aims to identify employment patterns, compare salaries, investigate geographic differences, and explore employment trends over time.

## Dataset

**Source:** [U.S. Bureau of Labor Statistics (BLS)](https://www.bls.gov/oes/tables.htm)

**Primary dataset:** May 2023 Occupational Employment and Wage Statistics (OEWS).

Additional historical datasets will be used to investigate changes in employment over time.

**Note:** Datasets are not included in this repository, in accordance with the assignment requirements. They can be downloaded from the official BLS website.

## Technologies Used

- Python
- Jupyter Notebook (Anaconda)
- Pandas — Data manipulation and analysis
- NumPy — Numerical operations
- Matplotlib — Data visualisation
- Seaborn — Statistical visualisation
- Git and GitHub — Version control

## Research Objectives

1. Identify AI-related and software development occupations with the highest employment levels.
2. Compare annual wages across selected occupations.
3. Investigate the geographic distribution of technology employment across US states.
4. Explore relationships between employment levels and wages.
5. Analyse historical employment trends using datasets from previous years.

## How to Run the Project

1. Install Anaconda and launch Jupyter Notebook.
2. Clone or download this repository.
3. Download the required datasets from the BLS website.
4. Place the datasets inside the `data/` folder.
5. Open `notebooks/employment_analysis.ipynb`.
6. Run the notebook cells in order.
